# チャット名の状態管理

主エージェントが、セッション全体の目的と現在の状況に基づいて親チャットの表示名を更新する。
サブエージェント自身のチャット名や実行識別子は対象にしない。

## 命名形式

```text
状態絵文字 [工程] タイトル
```

- 状態絵文字は次の7種類から1つ選ぶ。
- 工程は `調査`、`設計`、`実装`、`検証`、`レビュー`、`マージ`、`導入` など、現在の作業や待機に対応する短い語句にする。
- タイトルはセッション全体の目的を短く表し、工程の変更だけでは置き換えない。
- 既存の状態絵文字と工程は置き換え、接頭辞を重ねない。
- ユーザーが指定したタイトルや命名上の例外を優先する。
- 秘密情報、認証情報、非公開の内容を不用意に表示名へ含めない。

## 状態の判断

| 状態 | 条件 |
| --- | --- |
| 🔄 | 作業中・再開中。 |
| ☑️ | 今回の依頼・中間ゴールは完了したが、セッション全体の最終ゴールは未達成、または達成を確認できない。 |
| ✅ | セッション全体の最終ゴールを達成したと確認できる。 |
| 🔍 | PR を作成し、実際にレビューを依頼して結果を待っている。 |
| 🙋 | ユーザーへの質問・承認・確認待ちで、その回答が次の作業に必要である。 |
| ❌ | エラーで作業を継続できない。 |
| ⏸️ | ユーザーの中断指示、優先順位、依存作業などの都合で、意図的に保留・中断している。 |

会話で合意された全体の最終ゴールと、今回の依頼の完了条件を区別する。
新しい中間依頼が来ても、全体の最終ゴールをその依頼だけに置き換えない。
ユーザーが明示的に全体ゴールを変更した場合は、その変更に従う。

複数の条件が重なる場合は、現在の継続・待機・中断の理由を反映する。
例えば、中間成果が完成していても、次の作業にユーザーの承認が必要なら 🙋 にする。
独立して進められる作業が残っている間は、質問や外部処理の待機だけを理由に作業全体を待機扱いにしない。

- 返答の終了やサブエージェントの担当作業の完了だけでは、✅ にしない。
- 全体ゴールの達成が不明でも、今回の依頼が完了していれば ☑️ にできる。
- PR 作成、Draft から Ready への変更、CI の待機だけでは、🔍 にしない。
- レビュー結果を受領して修正を始めたら 🔄 に戻す。
- 復旧可能なエラーへの対応中は 🔄 とし、エラーで継続できなくなった場合に ❌ にする。
- 保留・中断の事実がない場合は、単に返答を終えることを理由に ⏸️ にしない。
- CI などの外部処理を待つ場合は、`🔄 [CI待ち] タイトル` のように工程欄で表せる。

## 更新手順

1. 開始・再開時、工程や待機理由が変わった時、最終返答の直前に、全体ゴール・残作業・現在の状況を照合する。
2. 既に把握している現在の名前と照合し、同じ名前なら更新しない。
   細かな進捗やログの追加ごとの改名は行わない。
3. 実行環境に提供されたチャット名変更ツールを確認する。
   Codex アプリで `set_thread_title` が利用できる場合、現在の親チャットには `threadId` を省略して `title` を渡す。
   別のチャットへの変更は、その対象への明示的な依頼がある場合だけ行う。
4. ツールの結果から、対象と適用後の名前を確認する。
   成功応答に名前が含まれない場合や結果が不明な場合は、利用可能な読み取りツールで対象チャットを確認してから次の操作を判断する。
5. ツールが利用できない場合や改名に失敗した場合は、未適用であることと推奨名を簡潔に伝え、本来の作業は継続する。
   改名の失敗だけを理由に本来の作業を ❌ 扱いにせず、セッション保存ファイルや内部データベースの直接編集で代用しない。

命名のためにレビュー依頼、承認確認、保留、作業の打ち切りを新たに発生させない。
サブエージェントを利用する場合も、担当結果・検証結果・未完了事項を主エージェントが全体ゴールと照合し、親チャットの状態を判断する。
強制終了やツールのない環境では表示名が実際の状態とずれる可能性があるため、再開時に改めて判断する。

## 判断例

| 状況 | 表示名の例 |
| --- | --- |
| 修正に着手した | 🔄 [実装] 通知の重複を修正 |
| 設計依頼は完了し、全体ゴールの実装は残る | ☑️ [設計] 通知の重複を修正 |
| 合意した修正と必要な検証をすべて完了した | ✅ [検証] 通知の重複を修正 |
| PR を作成し、実際にレビューを依頼して結果待ち | 🔍 [レビュー] 通知の重複を修正 |
| 次の作業に必要なユーザーの承認を待っている | 🙋 [マージ] 通知の重複を修正 |
| 必須ツールのエラーで継続できない | ❌ [検証] 通知の重複を修正 |
| ユーザーの指示で作業をいったん止めた | ⏸️ [実装] 通知の重複を修正 |
